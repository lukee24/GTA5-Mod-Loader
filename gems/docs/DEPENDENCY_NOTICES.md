# Dependency notice coverage

GEMS-owned source is under the MIT license. This does not replace the licenses of
third-party packages or grant rights to game data, mods, names, or trademarks.

`DEPENDENCIES.json` is generated by `npm run licenses` from the installed, locked
production dependency graph. It records package metadata and license/notice files
actually present in those npm packages. It does not claim to be a complete legal
review or a complete list of development tools, Electron/Chromium components, or
the optional .NET SDK/reference assemblies.

The current inventory contains 43 packages including GEMS. Two installed packages
declare licenses in metadata but ship no separately named license/notice text
captured by this script: `boolbase@1.0.0` (ISC) and `@nodable/entities@3.1.0` (MIT).
Those absent package files remain recorded as empty `texts` arrays. Their
upstream license texts have now been preserved separately below, with pinned
provenance, rather than silently substituted into generated package evidence.
A future bundled desktop binary release must still review notices for its exact
distributed dependencies and runtime.

This source release excludes `node_modules`, Electron/Chromium binaries, native
SDK binaries, compiled game assistants, downloaded mods, game files, local test
logs and screenshots. Dependencies are obtained by developers through their own
package-manager installation.

The bounded RPF reader's research reference and MIT notice are preserved at
`packages/rpf-engine/NOTICE.txt`. The optional ScriptHookVDotNet Enhanced source
record and upstream zlib/third-party notices remain under
`native/game-assistant/third_party/shvdne/`; see
`native/game-assistant/BUILDING.md` for the separate, verified SDK setup.

The GEMS icon is generated by `scripts/icon.ps1`. No Rockstar logo, game asset,
commercial mod, or third-party author preview is included as a project asset.
