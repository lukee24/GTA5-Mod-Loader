# GEMS自建安装清单（0.1.35）

包根可提供gems.mod.json。format必须数字1，files为1至20000项，每项source/target为明确相对文件路径；一源一目标，大小写重复拒绝。source必须是实际包内文件；全部映射存在才替换推断目标，不以不完整计划宣称成功。目标能否安装仍须Installer规则、游戏检查、冲突/风险确认及事务备份，解析成功不等于安装或游戏加载。

可选name/author/version/source如提供必须非空字符串：名称/作者最多200、版本80、来源2000字符，无控制字符；两端空白规范化。source必须有效无嵌入账号密码的HTTPS网址，不访问链接，不证明作者/来源/许可真实。错误可选字段不能再默默丢弃；老自建包需作者修正或移除无效字段，软件不自动改原包。

真实清单读取最多1MiB，普通独立文件、无连接/硬链接，严格UTF8，观察到读取变化拒绝；扫描使用之前SHA核对，摘要不同即使文件长度相同也拒绝。现有JSON不接受BOM。身份检查不是原生锁或最后TOCTOU/断电保证。

示例：

```json
{"format":1,"name":"本地测试配置","author":"作者","version":"1.0","source":"https://example.com/mod","files":[{"source":"config.ini","target":"mods/config.ini"}]}
```

未知附加字段不会执行，不能用清单命令启动程序；不自动添加DLL或替换核心游戏。文件索引只构建一次，原受保护路径/可执行风险与覆盖确认保留。

验证npm run test:gems-manifest：12项实际本地清单/UTF8/链接/变化/摘要和映射准入，核心397/397/编译通过。20k映射是元数据算法夹具，不是20k物理文件或内存/IO压力。原Electron被3077阻止，本版没有重试，不宣称IPC/UI、作者资源或Enhanced游戏/完整商业验收。
