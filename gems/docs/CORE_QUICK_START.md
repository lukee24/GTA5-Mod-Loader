# GTA5模组加载器使用说明

本轮先交付以车辆为主的核心功能；高级人物、服装、摄影等留给后续维护。当前仍是开发版，软件流程通过和游戏内模组通过分别记录。

## 启动与导入

运行交付的安装器，安装后打开程序；也可运行便携EXE。现有0.1.86界面和文件仍显示旧名GEMS。首次使用先在“设置”选择GTA V Enhanced游戏目录。错误目录不会被当成可安装目标。

在“导入模组”选择受支持的包或文件夹，先查看扫描报告、原作者说明和真实安装计划。车辆中心可检索已记录车型、分类、收藏并查看安装信息。文件识别、资源头版本和生成名称都不能单独证明车辆已在游戏加载。

**新增车辆包若需要DLC注册，或需要Legacy→Enhanced转换，当前会阻止自动安装。** 这些路径尚未打通。不要把手动复制dlc.rpf当成已支持，也不要为了通过检查删除阻塞提示。受支持的普通文件安装与已经正确注册车型的助手操作，按各自实际范围使用。

## 安装、停用与恢复

确认安装计划中的目标目录与覆盖项。工具先建立并核对备份，再执行受支持写入。遇到备份失败、外部修改或未完成事务，先处理明确提示。

停用或卸载按本次安装账本恢复工具负责的改动；其他模组和外部修改不能通过清空目录处理。更新先选择对应的新版本、检查新增/替换/移除项，再确认操作。失败后可在“备份与恢复”检查中断事务和待恢复项。

## 依赖、启动和游戏验证

“性能与诊断”显示实际候选文件、版本证据及未知状态。“启动游戏”当前支持就绪Steam记录的启动请求；其他平台按限制处理。启动器发出请求或进程出现，不代表已经进入故事模式或模组已加载。

游戏助手没有自动部署，默认保留原七分类，高级人物入口关闭。旧 DLL 已在 Enhanced 1.0.1158.16 故事模式加载，F5 中文菜单、原版 Adder 生成、收藏和车门动作已观察；修复请求执行后生命/引擎读回1000/1000，未测试受损恢复。Alt+G、驾驶和其他操作没有因此通过。0.1.86 的速度修复 DLL 已加载，但日志占用和 ERR_GFX_STATE 使游戏复测未完成。请先看[最终状态](../../docs/CORE_RELEASE_STATUS.md)，不要覆盖原有插件来试错。

车辆实际验收需要使用有权使用、属于声明支持路径的样本：安装/启用→进入故事模式→确认相关模块和车辆实际加载→生成或驾驶并操作→退出→停用/恢复→再次检查游戏。保留版本、模组和依赖信息及实际日志/截图。没有完成这条流程的项目显示“待实测”。

遇到问题可导出本地日志，附上操作步骤和错误。导出前检查是否包含本机路径。软件数据和备份保留在本机，不因卸载程序而自动清空。
