# 数据库打开快照检查（0.1.36）

已有gems.sqlite先只读检查独立普通文件/容量（256MiB）及完整读取。检查读取前后设备、文件标识、字节长度、纳秒修改/元数据时间和链接数量，以及路径对应文件身份；硬链接/连接或观察到变化拒绝。不会自动改原库内容。

SQL.js初始化会让出执行权，因此读取后还可能出现外部修改。返回Store前再次检查WAL/journal/shm及当前磁盘SHA是否和读取字节一致；变化、删除或多链接拒绝并释放WASM。新库沿用现有最终保存门禁，不能覆盖异步阶段外部创建的文件或日志。异常日志不清理、不接管SQLite恢复，不关闭用户其他程序。

文件哈希提交复核也检查独立普通文件和路径身份。所有这些都是可观察变化的检测，不提供OS锁，最后检查后仍可能有外部竞态；不声称硬件断电、多进程压力、数据库内容全模式准入或自动迁移/恢复验收。
