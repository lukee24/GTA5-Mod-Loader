## 当前操作

0.1.20：下载报告与“已分析”记录一次数据库提交，失败不会出现孤立报告或查看未提交报告的入口；下载原包仍保留。已完成记录的错误提示与下一任务、真正中断子进程和重启核对通过。JSON关联记录总上限16MiB，缓存/原包不与SQLite组成整体事务，旧报告不自动修复。`npm run test:download-atomic-ui` 是真实离线后端种子和桌面/重启验证，不访问显示的夹具网址，不代表公网下载或游戏兼容。

1. 打开“模组商店”，选择模组类别、载具和品牌，再按当前真实结果中的类型/标签筛选。
2. GTA5-Mods上方提供应用内作者图片/版本卡片和已载入页搜索，可翻页扩大范围；全库搜索和直接下载未接入，作者页面下载仍须手动完成。原站浏览保留为辅助入口，登录/验证由用户处理。
3. GitHub 输入作者/仓库或仓库网址，点击“读取发布包”。只列最近 8 个版本中的正式公开 ZIP / OIV / OIVS 文件，不列草稿、预发布或 EXE 安装器。目录不是全网搜索。
4. 点击“下载并分析”。后台顺序下载，核对作者提供的 SHA-256；没有作者校验值时只计算本地哈希，并如实显示。下载后自动安全解压与扫描。
5. 在下载队列点击“查看安装检查”，进入现有安装计划。无法确认目标、Legacy 资源、未注册 DLC 或损坏资源会阻止安装。下载完成不等于安装成功或游戏验证通过。

浏览窗口支持 GTA5-Mods / GitHub 公开 ZIP / OIV 的下载拦截与受限下载器交接。只接收受支持网站 HTTPS 文件，不带登录 Cookie，不支持外部网盘或任意域名。不同网站下载流程、验证页面、RAR / 7Z 或鉴权要求仍可能导致交接失败；软件会报告原因，不伪造完成状态。真实官网下载和自动扫描目前已验收 GitHub 作者发布包，GTA5-Mods 已验收实际分类浏览与窗口隔离，尚无该站真实模组下载的完整验收记录。

Nexus 目前提供官方网站浏览入口，接口列表与授权下载尚未接入。其[接口使用政策](https://help.nexusmods.com/article/114-api-acceptable-use-policy)要求公开应用注册，禁止批量抓取后重新托管以及公开应用使用个人 API key。本工程不通过抓取或更换身份绕过这些规则，也没有代用户申请注册。需要正式应用注册、合适的授权方式与平台下载规则验证后，才能开放对应的原生目录和自动下载。

## 分类依据

分类依据实际站点标签和作者文字，属于可解释的候选分类；实际下级选项只列已载入结果存在的内容。作者文字可能提及其他车型、游戏版本或用途，真实资源类型仍由下载后的扫描报告确认。网页保持网站原文；软件导航、状态和错误解释使用中文，来源权利与真实游戏验证分别核对。

## 下载与安全边界

- 下载队列上限 30 项，单包 1 GiB，总下载时限 30 分钟，连接空闲时限 30 秒。API 响应限 4 MiB。
- 独立 UUID 目录、排他写入、原包保留、大小和 ZIP 头检查、SHA-256 比对、最多 5 次重定向；只允许固定官方网站和已知 CDN，拒绝 HTTP、凭据网址、私网与保留 IP。
- 当前电脑的代理 DNS 返回 fake-IP 地址。下载器没有放行这些地址；针对固定网站域名，必要时用固定公网 Cloudflare HTTPS DNS 回查，并将实际连接固定在校验过的公网 IP。TLS 继续核对原网站证书。该回查会向 Cloudflare 发送待访问的网站域名，不发送模组内容或本地日志。参考其[官方 DNS JSON 文档](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/dns-json/)。
- 网站窗口使用独立、非持久化会话，无 Node、preload 或 GEMS IPC。默认拒绝权限请求；禁止导航到本地 / HTTP / 非受支持域名。网站的登录、付费和验证码不能由 GEMS 绕过。
- 失败项目不妨碍后续任务；取消会中断下载流。崩溃后未完成记录标记为“已中断”，没有断点续传。停止扫描阶段的取消尚未支持。
- 下载文件位于用户数据目录 `downloads/<下载ID>/`，扫描副本位于 `imports/<导入ID>/`。没有自动清理策略，原包与扫描缓存会占用额外空间。
- 安装继续使用原有事务、备份、游戏运行守卫和覆盖 / 二进制确认。不会从网站直接写入游戏目录。

## 商业发行边界

网站浏览和作者公开下载不赋予 GEMS 再分发、转售模组或重新托管目录的权利。软件收费范围、平台接入许可和模组许可需要分别核实。当前没有作者授权清单、签名发行包或所有网站的批量接入授权，不能把这一开发版本称为已完成商业发行验收。

公开发布接口依据 [GitHub Releases 官方文档](https://docs.github.com/en/rest/releases/releases#list-releases)。GTA5-Mods 原站条款见[使用条款](https://www.gta5-mods.com/terms)，车辆标签组合参见[奔驰 SUV 分类](https://www.gta5-mods.com/vehicles/tags/suv%2Bmercedes-benz)。没有从这些资料推定商业镜像授权。

## 来源收藏（0.1.5）

0.1.10 网络等待：API/资产请求每次跳转从连接到响应头最长 30 秒，公共 DNS HTTPS 回查最长 10 秒；正文采用原空闲与任务总时限，下载总时限仍为 30 分钟。连接未建立时取消也能及时结束。计时器和网络异常不放宽 TLS、官方域名或公网地址保护；不会自动重复请求被网站拒绝的内容。网站窗口与文件事务仍按既有退出规则处理。

0.1.9 网站窗口：首次打开最长等待 45 秒。关掉网站会取消当前打开任务，可继续使用桌面；关闭 GEMS 会销毁它创建的网站窗口并等待文件事务收尾。已进入网站后，站内导航不占桌面操作锁。超时请检查网络后重试，软件不会建议绕过证书或网站身份验证。实际窗口/下载回归证据见 TEST_REPORT.md。

输入公开 GitHub 仓库，可在“收藏名称”填写 80 字以内的中文名称，点击“保存来源”。最多保存 50 个来源，重复仓库大小写不另建记录。收藏只表示用户保存了网址，不代表仓库存在或模组兼容。读取成功后保存当次发布文件数和时间；过滤后的匹配数量可能不同。

下次打开软件会恢复上次使用的仓库。请点击“读取发布包”取得最新目录；启动和选择收藏不自动联网，也不会从数据库恢复旧下载链接。保存或切换到不同仓库、删除当前收藏时，旧仓库的发布目录会清除；同一仓库改名保留当次目录。移除收藏保留下载文件、扫描副本、模组与备份。未知版本或无效收藏记录会提示并保留，不自动迁移或打开其中的网址。

收藏保存在已有用户数据目录的 gems.sqlite 中，无账号、Cookie、凭据或下载链接。当前不支持 Nexus/GTA5-Mods 原生目录收藏或自动更新；它们的官方浏览入口保持现有范围。

复现：npm test 包含 11 项来源后端测试；npm run build 后运行 npm run test:source-library-ui，实际读取公开 API、退出重启应用并检查来源保存、过期下载拒绝、切换、改名、删除和双主题布局。此 UI 检查需联网，不下载或安装游戏插件。
