# 环境快照捕获与恢复准入

当前0.1.51。snapshot-plan负责完整捕获清单/记录schema和文本预算，snapshot-records负责有界SQLite读/新记录写入，snapshot-report生成前实际核验备份内容。Backup.snapshot在第一笔内容前执行计划与main预算callback，旧两参数调用仍完整校验文件映射。

每个源必须是对应gamePath+relative的实际普通文件；Windows路径大小写查重、只捕获mods/scripts或根ASI/INI/DLL，路径最多4096字符、20k条目、每文件最多20GiB。整张清单先通过再调用put；捕获是读取，不执行文件。目录层链接拒绝；源硬链接只读未额外禁用。捕获内容可包括当前Installer不支持恢复的程序/脚本，计划仍拒绝这些写入，不混同。

DB最多10000条/每条8MiB/总32MiB，SQL在JSON前限量；日期/id/key/目标/hash/未知字段校验。实际header与每条64字符hash的紧凑JSON预算提前计算，不保存空hash模板；同id新记录和sidecar已有路径拒绝覆盖。DB与sidecar/blobs不同步原子，故障可保留正确孤立内容，不擅自清理。

恢复报告先完整schema/当前目录检查、每个blob真实存在/大小/SHA核验，报告文件再由Installer原游戏守卫、禁止目标、覆盖/二进制确认与事务处理。根DLL可能原版游戏组件，明确警告但尚未存游戏构建/归属；不能保证跨更新恢复。空环境可捕获记录，空报告没有可恢复文件；不会删除后来新增内容，不是完整时间点恢复。

UI只改记录数说明与空按钮禁用/中文title，原3077未解除，尚未实际UI/IPC验收。12项/定向32/核心557/构建通过，范围和早期失败详见TEST_REPORT；实际隔离文件/库/回滚/重开通过，根DLL/bat只是未执行文本，不是作者MOD/SDK加载或故事模式。10001行/约35MiB空白JSON/20001重复输入仅预算准入，非真实大环境压力。
