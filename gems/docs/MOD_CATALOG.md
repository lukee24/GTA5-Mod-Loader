# 应用内模组目录（0.1.25）

打开“模组商店”，上方直接显示从网站读取的真实模组卡片，包含作者图片、名称、作者、版本、站点下载量/评分和兼容信息。卡片不是已安装车辆；作者预览也不是本机游戏渲染结果。

## 操作

1. 选择模组类别。车辆、人物、武器、地图与房产、脚本、图形和工具分别读取对应公开目录。
2. 车辆可继续选择汽车、摩托车、飞机、直升机、船舶等站点载具分类。汽车可按品牌读取，例如兰博基尼。
3. “实际类型”和“实际标签”只列出当前返回条目里存在的内容，不预置所有轿车/SUV等子项。型号、作者和版本可以在应用内搜索。
4. “载入下一页”扩大当前检索范围。搜索目前覆盖已载入页，不能宣称已实现网站全库搜索；GTA5-Mods的robots规则限制自动访问搜索路径。
5. 已读取的GitHub发布包可以合入相同卡片视图，并通过既有“下载并分析”真实进入下载队列。GitHub仓库仍在下方来源区域选择，不是所有公开仓库的全网索引。
6. 读取等待期间按钮和网站查询条件立即锁定。失败可“重试第N页”，保留此前成功页，不跳过失败页；“重新读取目录”清空网站条目，从第一页重建，已读取的GitHub发布包仍属于其独立来源。重复ID更新版本、实际类型和标签，不重复计数。网页在翻页之间变动可能造成缺项，这不是固定内容快照。

GTA5-Mods公开分类页及作者缩略图已接入。其下载跳转路径被robots规则排除，当前卡片提供“查看下载方式”和作者页面，**尚未实现该站全自动下载**。Nexus尚未完成应用注册和用户授权，目录与下载不伪装可用。网站规则和接口权限可能变化，读取拒绝时显示原因，不反复尝试或改用伪装身份。

## 兼容信息

作者页面打开失败会在下载说明窗口内显示原因，可以重试；等待时不会重复提交。仍可关闭或按Esc返回，关闭不一定取消已经发出的系统浏览器请求。关闭后旧请求结果不会影响另一个模组的窗口。

- 有实际Enhanced标签：作者标注Enhanced，资源与游戏仍待验证。
- 作者标题明确仅Legacy：显示作者声明，独立资源核验仍待执行。
- 其余：增强版支持未知。不因网站分类、文件名或图片把资源判定为可安装/可加载。

目录没有替代下载后扫描、依赖、冲突、备份和真实游戏验收。下载/识别成功与安装、DLC注册及游戏生成分别记录。

## 边界与来源

站点抓取规则须为有效text/plain/UTF8，最大512KiB；参考[RFC9309](https://www.rfc-editor.org/rfc/rfc9309.html)的分组与匹配，动态匹配避免复杂通配回溯。项目4096、规范化模式4096字符、地址8192字符，总计算预算800万；格式/容量或计算无法确认时停止，不截断后放行。无效内容不缓存；不会自动循环重试。实际客户端标识一直为GEMS-Mod-Studio，不模拟其他爬虫。此实现对异常行更严格，未完整解释Crawl-delay等扩展，不称完整协议认证；抓取规则也不证明商业授权。

元数据与来源条目从最近成功读取起五分钟有效，过期需要重新读取；系统时钟回退时也失效。成功重新读取第一页会清除同一站点目录已缓存的后续页，下一次翻页重新读取；刷新失败保留此前仍有效缓存。奔驰/迈巴赫等共享同一站点分类地址时，共用页面数据但分别按选择品牌筛选，不能因为地址相同带错查询条件。

同一地址的共享读取中，加入者取消只停止自身等待，首个调用的请求仍可继续；首调用失败会使其他尚在等待的调用失败。图片输出前核对当前引用和条目有效期；12个会话图片缓存不保证同一URL的像素内容即时更新。以上不构成服务端一致快照或全网索引。

每页最多60条、单次页面4MiB、每个目录最多20页，卡片最多显示200项并提示继续缩小检索范围。元数据缓存最多24页、5分钟；robots缓存1小时，读取失败或不允许时停止。图片通过后台公网IP/HTTPS验证，限制1MiB、PNG/JPEG/静态WebP、每轴最多1024像素，不接收SVG或动画。真实站点.jpg地址实际返回WebP已通过实测；这里仅核对尺寸和受支持封装，浏览器负责解码，不称为完整图像鉴定。

图片按可见区域加载，经IPC提供data URL；桌面CSP未放行任意外部图片域名。后台最多3项并行只读任务，不占用文件修改独占门禁；退出取消网络并等待所有读取和文件任务。缓存不保存账户、令牌、Cookie或镜像全站。作者预览截屏/原始HTML/图片字节只留本机，不随源码和安装器分发。

实际公开目录读取不等于商业展示/再分发授权已获确认。商业接入还需保留各来源授权依据；[GTA5-Mods条款](https://www.gta5-mods.com/terms)、[抓取规则](https://www.gta5-mods.com/robots.txt)和[Nexus公开应用接口政策](https://help.nexusmods.com/article/114-api-acceptable-use-policy)为当前调查来源。Nexus不允许批量抓取再托管或以个人测试密钥代替公开应用注册。

实测证据见TEST_REPORT.md：20条兰博基尼、20条飞机、20条武器、真实500×333作者图片、实际搜索/分页/键盘对话框、深浅主题及小窗口。未完成全库索引、各站直接下载、全部细分类与商业/游戏终验，后续继续推进。
