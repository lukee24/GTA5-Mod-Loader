# 游戏启动与证据范围

本轮加入 Steam 的 GTA V Enhanced 启动请求。GEMS 核对选定目录、PE/RPF 文件头、Steam 安装记录与进程状态，随后只向系统发送固定 `steam://launch/3240220/dialog`。Steam / Rockstar 负责平台选项、账号和游戏启动。GEMS 不添加启动参数，不切换安全设置，也不保证平台直接进入故事模式。Epic / Rockstar 独立版本启动仍待实现和实测。

启动页的结果分开显示：

- 等待：请求已记录或交给平台，尚未看到游戏进程。
- 结果未知：外部接口报错或无法确认派发结果，不能断言没有启动。
- 检测到进程：仅证明进程存在；故事模式、模组加载、功能均未验收。
- 已退出：此前观察到进程，当前检查未发现进程。
- 已取消：用户确认平台启动已取消或退出，并且当前未检测到游戏进程。

请求前先持久化启动记录。等待/结果未知期间暂停游戏文件写入；重启 GEMS 不清除等待记录。进入启动页检查进程。若平台未启动游戏，请关闭或取消平台的待启动界面后使用“确认已取消启动”，不能在平台仍准备启动时解除等待。进程检测失败时保留原状态。GEMS 不终止 Steam、Rockstar 或游戏进程。

进入故事模式后，仍需逐项取得当前模组日志、预期功能画面与操作结果；退出、停用/卸载/恢复后再复查。启动请求、进程检测和编译均不能填入模组加载通过栏。

核心测试使用合成 PE/RPF 头、真实临时文件/数据库和替代进程/外部调用接口。它们验证请求与保护逻辑，不启动 GTA V。平台实测与游戏内验收结果见 [验收清单](ACCEPTANCE_MATRIX.md)。
