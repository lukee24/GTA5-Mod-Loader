# 桌面车辆目录与助手读取契约

0.1.80-dev.1的“导出数据库目录”保存当前数据库中已启用车辆的生成引用。它不部署助手、不注册DLC、不验证模型、不建立实时同步。导出行仍为`enabled=false`、`installState=prepared`、`requiresGameRestart=true`；助手读取后不会将这些准备行列为可生成车辆。人物与房产导出尚未实现。

桌面在打开保存对话框前核对与当前助手一致的边界：

- 最多2000个车辆生成引用；按引用计数，不是模组包数量。
- 整个UTF-8 JSON文件最多2MiB。优先缩进格式；必要时用紧凑格式完整保存。仍超限则停止，不截断数据。
- 车辆名称最多300个UTF-16代码单元；组合标识最多145；品牌最多80。原合法字段保留，不静默裁切。空品牌使用“其他品牌”。
- 生成名为1至64个ASCII字母、数字或下划线。生成名按大小写不敏感比较，不允许多个记录争用同一名称；冲突提示列出两条来源，不自动选中一条。

超限、重复或非法字段会停止整个导出，已有输出文件和模组、安装、方案记录保持原样；错误会写入本地诊断日志。保存取消也不会修改已有文件。输出路径仍受原有保护，不允许覆盖游戏、软件、原包或受保护数据目录。

这些是有界数据交换约束，不是游戏兼容结论。真实模型外观、实际生成、DLC依赖及卸载恢复须在精确版本故事模式中另行验收。
