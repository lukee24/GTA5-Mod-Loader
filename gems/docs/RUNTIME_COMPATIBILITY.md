# 运行依赖与实机验证边界

诊断页的运行依赖结果来自实际游戏目录的只读检查。工具不执行候选 DLL/ASI，不下载或替换依赖，不修改游戏文件。

`diagnose()` 返回的 `runtime` 包含游戏精确版本、每个组件的候选文件、独立普通文件检查、Windows x64 PE 头检查、稳定读取的 SHA256 和支持记录。读取受 32 MiB/文件上限约束；链接、同名目录、读取失败和读取期间变化均保留为未核实。哈希标识本次读到的字节，不证明发布者身份。

| 字段 | 含义 |
| --- | --- |
| `status: missing` | 未发现列出的候选文件；只有所选模组要求此依赖时，才构成该模组的依赖缺失。 |
| `status: unsupported` | 已发现 ScriptHookV 候选，但游戏版本不在下述有日期的作者支持表中。这不是已经观测到崩溃的结论。 |
| `status: unknown` | 已发现候选但身份、完整性或兼容性仍未核实，或者文件无法安全读取。 |
| `support: matched` | 精确游戏版本与保存的作者支持表匹配；不表示已安装二进制匹配该发行包。 |
| `support: not-listed` | 精确游戏版本未在保存的作者支持表中列出，不用相近补丁号推断兼容。 |
| `support: unknown` | 游戏版本未知，或此组件没有经过核实的支持表。 |
| `gameplay: not-tested` | 此只读诊断没有执行故事模式加载、功能或恢复验证。该字段不会因文件、PE 头、哈希或旧日志存在而变成通过。 |

2026-10-26 核对 [ScriptHookV 作者发布页](https://www.dev-c.com/gtav/scripthookv/)：页面发布日期 2026-07-15，版本 v3889.0 / 1158.13，Enhanced 支持版本为 **1.0.1158.13**。当前本机检测到的 **1.0.1158.16** 未被该记录覆盖。此记录不是自动联网更新的保证；游戏或运行时更新后必须重新核对并保留来源日期。检测不到运行时文件时，`status` 仍为 `missing`，同时 `support` 独立显示 `not-listed`，避免遗漏其中一个问题。

ASI Loader 的候选包括 `dinput8.dll` 和旧名 `dsound.dll`。同时发现两个候选时提示核实，不能自动删除用户文件。ScriptHookVDotNet 必须结合实际脚本 API 核对 ASI、API DLL 和同一发布包；只看到任意一个文件不能证明依赖齐全。`ReShade.ini` 只是配置，不作为注入器存在证据。`dxgi.dll` 等名称也不能证明该 DLL 就是 ReShade。OpenRPF 与其他重定向器不自动视为等价。

实际验收需要独立保留：当前游戏版本和模组/依赖哈希、开始前文件快照、GEMS 导入/安装事务、此次启动产生的加载日志、进入故事模式后的预期内容或功能操作证据、退出后的停用/卸载/恢复记录，以及恢复文件与基线一致的校验。旧日志、文件复制成功、无匹配错误日志或游戏能启动均不能替代这些证据。
