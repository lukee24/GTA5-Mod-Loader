# 目录扫描上限与失败处理（0.1.33）

文件夹导入逐项读取，不先创建整个目录列表。全部文件和目录合计最多40000条目；仍限制20000个普通文件、20GiB总文件字节和64层嵌套。空目录也占条目预算，根目录本身不计；第40001条读取后立即拒绝，不读取其内容或继续遍历。原生目录缓冲32条，递归最多65个目录句柄；输出文件清单仍保留最多20000项，不声称所有内存固定常数。

超限或读错时，当前/父目录关闭，导入失败，不把部分清单当完整成功。输入不删、不改。文件夹先走完扫描再复制，读取期间失败留下独立imports/UUID/failure.txt和空contents；后续阶段失败可能保留已经准备的缓存。全部失败工作区不自动清理。批量明确文件导入中，单个失败仍可继续下一包；修正目录问题后可手动重新导入。

测试：npm run test:scanner-walk，npm run test:scanner-walk-ui。五项核心新增，最终全量377/377；条目超限是40001虚拟空目录枚举、固定祖先缓存及模拟不存在的子目录，不能当真实Windows目录容量/内存峰值压力。正常中文文件、子目录读错、65层为真实隔离文件。桌面原IPC/SQLite/源和缓存均真实，只有选择路径和原生目录读取错误在测试进程注入。未模拟扫描成功回复，未接游戏目录。

同步读取、路径核对与文件复制仍在主进程，慢磁盘/锁定目录可能等待；未实现独立扫描工作线程、实时取消、原生锁/所有TOCTOU或断电保证。路径与字节限制不证明MOD无毒、Enhanced兼容或在游戏生效。ZIP沿用20000压缩目录条目/20GiB/压缩比例等独立限制，RAR/7Z仍未接入。
