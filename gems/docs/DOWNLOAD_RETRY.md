# 下载记录手动重试（0.1.29起）

0.1.30增加下载文档有界准入，异常只停下载/重试并保留数据，正常启动整理一次提交；健康重试离线回归通过，没有重新发起已受限的公网请求。详见DOWNLOAD_RECORDS.md。

“下载与更新”和商店下载队列现在提供“重新下载”。仅本版新建、保留公开GitHub发布标识的失败/取消/中断记录可用；不猜旧记录或网站浏览下载的地址。按钮禁用时显示原因，用户可以回到来源重新选择发布文件。软件不会后台自动重试拒绝访问，不绕过登录、认证、会员或站点限制。

重试先重新读取同一作者仓库最近8个正式版本，核对资产ID、名称、来源页面、版本、作者声明大小和摘要；删除、超出当前目录范围、版本/文件信息变化会停止，让用户重新检查当前发布。来源选择为空或当前选择其他仓库不会把重试改成另一模组。作者没有摘要时仍不能保证内容完全相同或可信，更不能保证Enhanced兼容。

记录仅增加公开的id/version/size/digest及retryOf/retryRoot，不持久化下载URL、授权令牌或凭据，不变更SQLite表/schema版本。下载地址来自新读取的发布列表，渲染器只能提交已有记录ID。旧记录原样保留；新任务有新UUID目录、原失败/重试分支关联，并沿用实际下载大小、作者SHA、归档检查、安全扫描及报告关联提交。残留partial或已下载原包不复用、不覆盖或自动删除，暂不支持断点续传/缓存清理。

同一原下载的分支已有进行中任务时拒绝重复排队；任何分支完成分析后，原失败记录显示应查看新记录，而不能再重试。失败、取消或中断的新分支仍可显式重试，沿用原关联根。队列仍最多30项，单包1GiB，服务保存/通知故障继续停止；缺关联、无公开标识或不匹配元数据拒绝，不制造下载成功。界面只展示最近200条，超出可见范围需在来源重新选择。

已验证范围：新增11项、核心344/344；真实SQLite/ZIP/哈希/扫描、原文件与记录保护、新队列/重复分支、取消/中断、保存拒绝/重开、元数据变化/删除/无效来源和取消。实际Electron原IPC与完整后端离线网络夹具通过，包含首次目录错误反馈/再次读取、新包/报告入口、旧格式禁用、深浅/1024布局、实际退出重启和原生SQLite只读复核。离线HTTP/DNS响应均明确注入到自有测试进程，不替换UI或IPC成功回复；不代表公网/TLS/作者实际资源或游戏效果验收。

本轮真实公开GitHub验收在API读取时因访问/请求额度限制失败，未再请求或改身份/登录。证据分别为download-retry-ui-public-blocked.log、download-retry-ui-current.json（passed=false）和download-retry-offline-ui-current.json（publicNetwork=false）。历史其他版本的公网下载通过不替代本功能的新公网重试验收，当前仍待验证。

开发复现：`npm run test:download-retry`、`npm run test:download-retry-offline-ui`。网站恢复访问后才运行`npm run test:download-retry-ui`；测试不会安装或加载下载包。图片为明确离线夹具，不是作者目录截图。商业展示/分发许可、可信安装发行和全需求终验未因此完成。
