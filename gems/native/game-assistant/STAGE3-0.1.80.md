# 0.1.80-dev.1 原生 Stage 3 开发与验证记录

本阶段补充原需求 R027 / F041 / F062 的世界、天气与时间代码路径。**没有部署到游戏；没有实际加载或故事模式效果证据；不能写本轮验收通过。** `gameValidationStatus` 保持 `not-tested`，`desktopInstallationAllowed` 保持 `false`。编译与下述离线夹具仅证明对应软件路径。

## 使用与范围

F5 或 Alt+G 打开同一菜单，左右切换到“世界天气与时间”，进入五个子页。上下选择，`+/-` 调整数值草稿，回车执行；Esc 返回。时间、密度、速度有可见滑条，目前没有鼠标拖动或手柄操作。每次动作后必须重新显示完整条目及提示，才接受下一次确认。超长提示不会被无声截断后授权执行；重新打开菜单或换行选择可以恢复正常操作，旧结果保留在日志。

| 原始子项 | 本版实际代码路径 | 操作/恢复限制 |
| --- | --- | --- |
| 小时/分钟、日夜 | 0—23/0—59 草稿滑条，一次写入完整时刻；12:00 / 22:00；真实时刻读回 | 调整前时刻仅在本次连续安全上下文记录，主动重设不补偿经过时间、日期或任务 |
| 冻结/恢复时间 | 明确请求暂停或解除暂停，二次确认 | 不读取 SDK 内部地址型暂停 getter；解除可能解除其他脚本的暂停，不能称只恢复本助手开关 |
| 行人/交通密度 | 独立 0—100% 草稿和开启状态；每个允许 Tick 各最多一次请求 | 停用/守卫失效后停止请求，不写默认值，不清理实体，不读取或恢复其他脚本倍率 |
| 世界速度 | 10—100% 一次性请求，二次确认 | 不读取不可靠全局原值，不自动恢复；手动提交 100% 是新请求，不是还原未知原值；0 暂停尚未支持 |
| 重力 | 9.8、2.4、0.1、0 四个固定 SDK 预设，二次确认 | 使用 SDK typed setter，不自行访问内存；不读未知原值，不恢复已发生的位移/损伤；手动 9.8 仅新请求 |
| 警察行为 | 忽略/关注当前玩家、开启/停用派警四个一次性请求 | 忽略会使 NPC 执法车停止；反向设置不能还原原速度；不把警方 getter 的降级 false 当原状态 |
| 天气 | 15 个 SDK 候选，6 类固定图标卡片；二次确认；记录 build、请求和 previous/next | 始终可见“SDK候选·未实测”；没有任何当前 build 已通过列表；不强制每帧覆盖图形 MOD、不承诺完整天气恢复 |
| 附近冻结 | 扫描 10 米内最多 128 个候选，最多 32 个保留冻结记录；10 秒固定计划；执行前重查 | 暂限接地、不在水中、速度≤0.5m/s、无乘员/附着/任务/脚本归属的行人和空车；排除玩家与玩家当前车；其他类型未完成 |
| 条件解冻 | 只处理本助手本会话实际更改过、身份和安全条件仍一致的目标 | 原来已冻结的不取得解冻权；外部变值、目标失效或守卫间断不乱写。失效身份和中断遗留持续计数，不能点恢复就归零 |
| 临时实体清理 | 本实例实际 CreateVehicle 返回对象的双层创建账本，上限 16；10米内当前符合安全条件车辆；预览+二次确认 | 不认领旧版本已释放对象、陌生同模型或其他 SHVDN 对象；不可撤销；占用、冻结、附着、身份/归属变化跳过；部分失败单独记录 |

清理是“受支持临时车辆”的一条实现链，不等于清理所有世界临时实体。生成成功后本版本保留管理记录，不立即交还游戏；不能保证脚本异常终止后执行清理，也不会跨脚本重载凭旧 handles 认领。前往附近安全清理页可主动处理符合条件的本实例车辆。守卫中断后撤销管理权限，保留未确认结果，不为了自动清理而越过守卫调用游戏。

SHVDN 所有脚本共享运行时 owner。**本地创建账本是必要条件，但仍无法辨别另一 SHVDN 脚本在同一共享 owner 内接管同一对象而没有可见状态变化**。同样无法辨别其他脚本对同一布尔值的无变化写入。上述边界是实际限制，不是绝对无损承诺。

## 实现接线

`WorldContracts.cs` 是真实控制器与生产适配器共享接口；`WorldController.cs` 控制请求、确认、会话和实体计划；`GtaWorldPort.cs` 在每次真实操作前重新检查故事模式、角色/实体身份及安全条件。应用没有复制 SDK 内存地址、没有新增数值 Native hash。时刻写入沿用已核实的命名 `SET_CLOCK_TIME` 契约，以一次调用代替三个分量连续写入。

`GemsAssistantScript` 的 Tick、按键、Rows、Abort 和创建车辆路径已实际接线。`SpawnCompletion` 在创建前消费票据，用 finally 收尾模型；登记、日志或释放异常均不会再授权同一票据创建第二辆车。创建和释放同时失败时保留两个异常。

`WorldMenu` / `WorldRaster` / `ChinesePanel` 绘制实际候选卡片、滑条和三行完整提示。图标及滑条只使用固定有限素材。世界会话曾中断、身份失效未确认等状态保留在子页和首页，后续普通操作不会清除。

| 触发/问题 | 修复 | 验证 |
| --- | --- | --- |
| 超大 delta 在乘 10 前溢出 | 控制器拒绝 -1/0/1 外的 delta，校验全部草稿 | 非法输入、边界倍率回归 |

| 最后 Guard 后乘员变化，旧 Safe 快照仍放行 | 冻结和删除在最终阶段重取全部安全快照 | 初次端口夹具 166 通过/2 失败的日志保留；修复后同用例和关联集共 178 通过 |

## 复现命令

从 `gems/` 用 PowerShell 7 和 .NET 8 SDK 执行；固定引用依赖按 BUILDING.md 准备。未安装到游戏。以下 `--no-restore` 使用本轮已经安装并锁定的依赖；新环境先按构建说明还原。

```powershell
dotnet build native/game-assistant/Gems.GameAssistant.csproj -c Release --no-restore --no-incremental -p:NuGetAudit=false
dotnet build native/game-assistant/tests/Gems.GameAssistant.Tests.csproj -c Release --no-restore --no-incremental -p:NuGetAudit=false
dotnet run --project native/game-assistant/tests/Gems.GameAssistant.Tests.csproj -c Release --no-build --no-restore
dotnet run --project native/game-assistant/tests/world-port/WorldPortCheck.csproj -c Release --no-restore
dotnet build native/game-assistant/tests/visual/VisualCheck.csproj -c Release --no-restore -p:NuGetAudit=false
& native/game-assistant/tests/visual/bin/Release/net48/VisualCheck.exe
& native/game-assistant/tests/verify-script-wiring.ps1
```

`NuGetAudit=false` 仅用于本次网络不能访问漏洞查询端点时的固定依赖构建，不改变项目锁定依赖，也不表示漏洞审计通过。全部结果仍为离线证据。
