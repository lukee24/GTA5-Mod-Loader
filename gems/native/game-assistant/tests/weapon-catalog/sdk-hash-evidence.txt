XML says input is converted to UTF-8 bytes. ASCII uppercase letters are mapped
to lowercase; backslashes to slashes; a leading quoted value receives special
substring treatment. Our accepted weapon-name domain is [A-Za-z][A-Za-z0-9_]{0,63},
so quote/slash and non-ASCII behavior is outside the accepted domain.

  StringHash static constructor -> byte[] allocation, RuntimeHelpers.InitializeArray,
