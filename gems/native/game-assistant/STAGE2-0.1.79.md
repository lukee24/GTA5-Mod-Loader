# 0.1.79-dev.1 原生助手：当前车辆链

此组接在 Stage1 基础与玩家链之后；Stage1 的源码ZIP、DLL、日志和图像保持独立。最终源码/构建指纹见 `artifacts/0.1.79-stage2-manifest.json`。本组没有部署 DLL、写入 GTA V 目录或进入游戏；所有实际效果仍为 `not-tested`，桌面安装保持禁用。

## 当前车原16项实现与限制

| 项目 | 实际代码行为 | 恢复与验收边界 |
| --- | --- | --- |
| 修复 | Vehicle.Repair；读EngineHealth/BodyHealth | 一次性，不回退损伤；外观与驾驶待测 |
| 清洗 | DirtLevel=0后读回 | 一次性；实际外观待测 |
| 翻正 | 仅停稳、接地附近、平坦且周围无其他车辆/行人的汽车，核验有限数值后旋转 | 一次性；地形采样不是完整碰撞证明，坡地/空中拒绝；实机碰撞待测 |
| 最大改装 | 二次回车确认后InstallModKit；Engine、Brakes、Transmission、Armor、Suspension只设置Count>0的最高索引，另请求Turbo并读回 | 性能槽最高档，不把外观件最后索引叫最好；记录每槽结果；中途失败可能已有部分改装，不自动恢复套件/档位 |
| 更换颜色 | 主色/副色子页输入6位RGB，typed CustomPrimary/SecondaryColor，读取实际色与自定义标志 | 一次性，不自动恢复原颜色模式；输入取消不写入 |
| 更换车牌 | 输入1至8位ASCII字母/数字/空格，字母转大写后设置并读回 | 一次性，不声称中文车牌支持；输入取消不写入 |
| 引擎开关 | IsEngineRunning读取/切换，记录原值和最后写入 | 只条件恢复可观测布尔值；游戏/其他MOD可再次接管 |
| 车辆无敌 | Entity.IsInvincible读取/切换 | 同车实体身份与状态匹配时条件恢复；换车不串写 |
| 打开车门 | 停车后枚举实际Doors，跳过损坏门，Open(false,false)并读IsOpen | 动画请求与即时读回分开，不声称动画完成 |
| 关闭车门 | 同上，Close(false) | 不把损坏门关闭请求当维修成功 |
| 车窗控制 | 汽车降窗用RollDownAllWindows；升窗请求前左/前右/后左/后右 | SDK没有升降位置getter；无窗/特殊车窗车型仍需实测，不把IsIntact当卷起状态 |
| 灯光控制 | 主灯二次确认后SetScriptedLightSetting强制开/关，读AreLightsOn；内灯独立开关 | 主灯未知原强制模式不可恢复；内灯只条件恢复可观测布尔值 |
| 轮胎修复 | GetAllWheels仅对IsBursted车轮Fix，再读取剩余爆胎数 | 一次性；两轮/多轴/特殊车轮实际效果待测 |
| 悬挂调整 | 二次确认，InstallModKit后在原厂(-1)和可用Suspension档位之间循环 | 仅改装档位，不含自由高度、HandlingData或液压；一次性不自动回退 |
| 速度相关设置 | 玩家驾驶、接地、当前不超过30km/h的汽车，+/-单次5km/h；Enter停车；有限数值和边界检查 | 不是持续限速/功率调节；不写未知原MaxSpeed；单次物理变化不自动回退 |
| 车辆收藏 | 按真实Model.Hash保存/取消；独立收藏页按hash发起原有受限模型加载与生成链 | 保存车型，不保存当前实体/改装；尚不与桌面favorite字段自动同步；模型不可用时失败，不伪造生成成功 |

另有第17行“恢复本助手车辆开关”。离开当前车、故事守卫失效后重新允许、脚本正常卸载时，会尝试恢复已记录的车辆无敌、引擎运行与内灯。恢复旧车不要求仍坐在旧车，但必须重新通过故事守卫、原车辆handle/模型/内存地址核对及最后写入值核对。旧车已消失或身份变化时保留未恢复日志，不写新车；恢复尚不确认时拒绝把记录直接替换为新车。

性能改装、悬挂与强制主灯的确认窗口为10秒；换车、守卫失效、切换选择/分类/关闭菜单会取消。颜色/车牌键盘输入返回后重新核对角色身份、当前车辆身份、停车条件，再允许写入。没有把所有一次性动作强行纳入恢复开关。

## 收藏文件保护

运行时存储目录为 `%LOCALAPPDATA%/GEMS/game-assistant/favorites-v1`。每次操作写独立临时文件、Flush后重命名为新的不可变JSON记录，不覆盖旧记录；以递增序号重建最终收藏。最多4096条记录/2048车型；损坏、超长、重复序号或链接路径拒绝处理，不清空历史。临时文件只清理由本次成功CreateNew创建的文件。该格式记录冲突会阻止继续修改，保留原始证据供修复；没有实现自动历史压缩。

## 本组修复与复测

- 停车/接地条件原本会放过NaN、Infinity或负值，现使用统一有限范围规则；速度请求拒绝极值和非法步长。
- 输入颜色/车牌期间可能换角色、换车或开动，现对输入后的实际环境重新校验。
- 一次性确认不能跨车、跨操作、超时或消费后复用；菜单确认行与实际执行key绑定。
- 收藏CreateNew失败时原本可能清理未归本次创建的同名临时文件，现用本次创建标志保护。
- HEX解析明确拒绝空白、符号、全角字符与非六位输入，避免NumberStyles接受首尾空格。

代码复测使用既有 .NET 8 纯C#测试工程及固定SHVDNE API编译，未新增依赖。最终离线测试402个断言通过；其中包含先前Stage1的229项、车辆规则/确认92项、输入/菜单28项、真实收藏文件53项。4类检查未执行：原桥接符号链接、收藏ACL拒写、收藏目录符号链接、收藏文件符号链接；环境无相应权限，不能写通过。文件独占占用/路径被普通文件占用已实际执行且原字节保持。

Windows GDI端口夹具执行实际ChinesePanel与VehicleMenu代码：213个断言（含200个动态帧），验证17行末项、确认行和三个子页。它不执行SHVDNE Native，也不能替代真实手柄/鼠标/游戏渲染测试。图片已人工检查；实际游戏FPS、GPU纹理、模型加载仍未知。
