# GTA5模组加载器：车辆核心范围

用户于2026-10-27明确调整范围：先把主要、能正常使用的功能做好，保留后续维护空间，控制额度。**本文件取代原45节完整蓝图作为本轮交付门槛。** 原需求和已有源码继续保留为维护路线图，不因延期而标记为已实现或验收通过。

## 目标

完成并交付GTA5模组加载器以车辆为主、能正常使用的核心版本。优先修好车辆模组导入识别、受支持格式的安装/启停/卸载、备份恢复、依赖诊断、启动和日志，保留已有可用车辆助手功能。集中修复阻断问题，执行必要关键流程测试并统一打包。高级人物、服装、摄影、完整转换等扩展留作后续维护。保护原游戏和用户文件，游戏加载、使用和恢复按真实证据报告。按2026-10-28最新决定，以开发中项目公开并准备Codex for Open Source申请，尚未完成的游戏测试和已知限制继续保留，不以全部游戏功能完成作为申请前提。

## 本轮验收项

| 项目 | 必需行为 |
| --- | --- |
| 启动与目录 | Windows应用正常启动退出；识别有效Enhanced目录，错误路径有明确反馈 |
| 车辆导入与管理 | 支持范围内的来源真实扫描、车型信息/文件记录、检索、收藏和安装计划可用 |
| 安装生命周期 | 明确目标及覆盖提示，备份后写入；启用、停用、更新、卸载不破坏原文件 |
| 恢复 | 写入失败处理已发生改动，按账本和哈希恢复，外部修改保留并提示 |
| 车辆助手 | 保留当前车辆菜单、生成/收藏及基础车辆操作；本次改动不使原入口退化 |
| 诊断与反馈 | 依赖和版本未知如实说明；启动请求、日志和错误可追踪 |
| 最终交付 | 用同一最终版本统一做必要回归、安装/启动/卸载检查，交付源码、程序及简短使用说明 |
| 游戏效果 | 对声明支持的车辆路径，用有权样本验证实际加载/驾驶或操作/退出及恢复；缺条件时保留待实测，不以构建或启动代替 |

高级人物运行入口默认关闭，已有研究和维护源码保留；不继续追加人物、服装、摄影等功能来阻塞核心交付。已实现并经软件检查的桌面资料功能可以保留。

## 必须公开的车辆限制

当前Legacy→Enhanced真实转换后端缺失；加密RPF修改和新Add-On车辆DLC注册尚未打通。不能把这些路径列作已支持，也不能把仅复制dlc.rpf写成车辆已经可用。核心版的可用范围必须与实际支持的文件安装和已注册车型操作相符。这些限制在交付说明和界面中保持可见。

历史完整矩阵仍用于后续维护，未完成扩展不再是本轮核心版的失败项；核心流程中的失败、安全恢复缺陷及虚假的能力声明仍必须修复。
