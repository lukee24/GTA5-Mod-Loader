# GEMS 0.1.82-dev.1 开发与验证记录

本阶段源码、原生DLL和软件证据已冻结，Windows安装版/便携版及独立完整源码干净构建已完成限定验证。完整项目未通过验收，真实Enhanced游戏加载、功能与恢复仍待实测，申请准备暂停。0.1.81的源码、安装器、便携包和309份证据已封存，原工程及旧版本保持。

## 首要修复：超级跳跃旧请求重用

0.1.81生产脚本夹具已复现：开启超级跳跃后，外层故事模式检查通过，实际提交前`RequireContext`拒绝；异常路径仅暂停菜单输入，没有停掉持续请求。同一角色恢复有效后的下一帧又提交跳跃。失败日志显示`enabled=True,calls=0`随后`enabled=True,calls=1`。此夹具直接编译生产Script，GTA宿主和动作端口为替身，不是游戏实测。

修复要求：所有已观察到的守卫中断、身份改变、提交异常、暂停/失焦和脚本结束撤销持续请求，恢复资格后需要用户重新启用。生产脚本已统一停止玩家移动请求，端口把身份与连续会话代次共同绑定。独立复测36项通过，包含原5类失败序列，26个生产.cs与最终冻结身份相同。

独立审查从已归档0.1.81源码重跑并扩充到5个边界，均观察到连续性不符合预期：内层守卫拒绝、失焦、暂停、跳跃API异常，以及读输入后角色变化再返回旧角色。其中失焦/暂停当帧仍提交且下一帧继续；其余旧请求未清。`player-review-0.1.82/baseline-guard-repro.txt`与`baseline-guard-result.json`保留exit1，这是旧版本失败证据，不是0.1.82候选测试结果。修复后必须原序列复测。

## 本阶段范围

- 原需求第23节“移动速度调整”：固定SDK公开`SetRunSpeedMultThisFrame`与`SetSwimSpeedMultThisFrame`的逐帧合同，提供真实菜单、独立数值和开关、键盘/逻辑手柄分发、逐帧提交与明确停止。
- 0..1.499有界且拒绝NaN/无穷；展示本助手请求和最近提交结果，不冒称读到了游戏最终倍率。停止时不写1.0并声称恢复未知外部原值。
- 普通F5隐藏菜单后仍需允许运动；停止功能与隐藏界面分开。部分帧提交失败后停止后续请求，不能声称撤销已经发生的本帧写入。
- 玩家动作使用独立键，避免现有停用玩家`speed`行误入车辆速度路径。超级跳跃纳入同一连续会话规则，保留生命/护甲/通缉/无敌/隐身/坐标的已有行为和条件恢复边界。

无限体力和完整故事主角切换仍缺可靠写入及恢复合同，保留未完成；模型替换不能冒称完整主角切换。原完整功能范围不缩减。真实效果、停止后的行为、其他脚本共存、物理键鼠手柄和加载/卸载恢复均另需目标游戏证据。

## 开发产物与使用

本版开发安装器为`gems/release/GEMS-0.1.82-dev.1-x64-setup.exe`，便携包为同目录`GEMS-0.1.82-dev.1-x64-portable.exe`。安装后从GEMS快捷方式启动；便携包直接运行。桌面软件安装不会安装原生助手，助手安装入口保持禁用。选择游戏目录后先查看环境报告；扫描结果、准备状态或文件写入不能作为游戏加载证据。

普通文件模组先导入、检查安装计划和依赖/冲突，再确认覆盖；停用/卸载按本工具账本恢复。外部改动或恢复阻塞应保留文件和账本，按提示检查原因，不能清空模组目录。详细方法见[使用指南](../gems/README.md)。源码构建从解压后的`gems/`执行`npm ci`、`npm run build`、`npm start`；原生SDK固定获取方法见`native/game-assistant/BUILDING.md`。
