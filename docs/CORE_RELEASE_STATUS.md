# GTA5模组加载器：当前状态与限制

更新于 2026-10-28，版本 **0.1.86-dev.1**。GTA5模组加载器作为开发中项目公开，优先维护车辆相关的主要流程，游戏中的剩余问题会继续修复。现有程序仍显示旧名 GEMS，本次对外更名不代表已重新打包程序。

## 已完成的软件流程

目录识别、模组扫描、车辆分类与收藏、受支持文件的安装启停更新卸载、备份恢复、依赖诊断、Steam 启动请求和本地日志已经实现并做过软件测试。安装失败、恢复中断和外部文件被修改等情况也有测试记录。

0.1.86 已完成桌面构建和最终便携程序的启动、退出检查。此前的安装、卸载和主要文件流程测试记录保留；本次没有重新执行全部历史测试，也没有在其他电脑验证。程序为未签名开发版。

公开源码后修复了数据库读取期间同长度改写可能漏检的问题，相关27项测试通过。该修复尚未重打本地0.1.86程序及源码ZIP；当前仓库源码领先这些本地交付包。详情见[本版记录](DEVELOPMENT_ACCEPTANCE_0.1.86.md)。

## 游戏助手的实际情况

在 Enhanced **1.0.1158.16** 故事模式中，旧版助手成功加载并显示 F5 中文菜单，原版 Adder 已实际生成，收藏和车门动画也做过局部测试。修复请求执行后，车辆生命和引擎读回1000/1000，未测试从受损状态恢复。附近被其他实体占用时，生成操作会拒绝。

随后发现静止速度设置没有效果，0.1.86 已将这处代码改为 `ForwardSpeed` 并通过针对性软件测试。新 DLL 已再次加载，但复测期间出现 SHVDNE 日志占用和 `ERR_GFX_STATE` 图形错误，后续输入无效。**速度修复、驾驶及完整移除后的游戏复测仍待完成**，暂时不能认为游戏助手已经稳定可用，桌面自动安装入口仍关闭。日志占用、输入失效和图形错误之间的原因还没有确定。

本次实验文件已按记录移除，原存档、配置和缓存文件已核对恢复。最后一次错误之后没有重新进入故事模式；此前正常进入原版故事模式的记录另行保留。

本机使用 SHVDNE v1.1.0.6。ScriptHookV 所用发行包标记为 v3889.0/1158.13，作者明确列出的 Enhanced 版本是1158.13，因此不能把这次1158.16的局部结果推广到其他版本或全部功能。运行时来源：[ScriptHookV](https://www.dev-c.com/gtav/scripthookv/)、[SHVDNE](https://github.com/Chiheb-Bacha/ScriptHookVDotNetEnhanced/releases/tag/v1.1.0.6)。

## 尚不支持

- 新增 Add-On 车辆的 DLC 注册、Legacy → Enhanced 转换、加密 RPF 写入。
- 将文件复制或“已启用”直接当作车辆在游戏中正常使用的证明。
- 对第三方车辆、全部按键、手柄、分辨率或其他电脑的通用兼容保证。

高级人物、服装和摄影等放在后续维护。详细步骤和版本信息见[本版记录](DEVELOPMENT_ACCEPTANCE_0.1.86.md)、[游戏助手说明](../gems/docs/GAME_ASSISTANT.md)和[功能清单](../gems/docs/ACCEPTANCE_MATRIX.md)。
