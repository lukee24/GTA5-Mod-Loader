- 桌面说明已明确“默认键位”且不读取游戏中的个人映射，避免把默认值当成实际配置。`npm run build`通过，保留第三方`use client`告警。
- 实际Electron助手7组导出/取消/临时安装备份与卸载恢复通过，0页面错误；浅色120%、980×760整窗DOM检查及原生捕获已保存。见`artifacts/0.1.81-assistant-initial-ui.json`和同名前缀截图。这是初始桌面dist，不能替代最终capabilities更新后的包验证。
- 固定SDK只读IL审查确认：`GetUserInput`暂停按键事件而轮询仍可读取按键状态。文字输入隔离与释放屏障已列为实现和回归要求。手柄control查询也不是物理设备连接证明，不能用离线信号夹具宣称实机手柄通过。
- 对既有冻结离线测试DLL的新专用目录重试仍为682项通过、4组ACL/符号链接权限分支未执行。没有修改系统策略，此结果不增加0.1.80已过用例数，也不证明新输入系统。
- 另用实际Windows目录联接点执行生产BridgeCatalog/FavoriteStore的4项读取/拒写检查通过，目标文件库存和哈希未变。该证据只覆盖目录junction，不能替代文件/目录符号链接和ACL用例。首轮私有测试工程引用路径写错导致编译失败，修正夹具后复测通过，原日志保留。

以上Windows样本和私有证据均位于工作区隔离目录。没有写入、启动或操作真实游戏；未签署任何整体功能通过结论。
